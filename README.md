# VSTEP Listening – Shopping & Money – Teacher | GitHub Pages (đã tích hợp Audio)

## Sử dụng trên GitHub

1. **Giải nén ZIP**. Bên trong có **21 file cùng cấp**, KHÔNG có thư mục con.
2. Upload **toàn bộ 21 file** vào root của repository GitHub bằng **Add file → Upload files → Commit changes** (không upload ZIP nguyên khối).
3. Vào **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root)**, chọn **Save**.
4. Mở URL GitHub Pages của repository. Trang chạy từ `index.html`.
